## 1. 产品定位与版本

### 1.1 星辰是什么

金蝶AI星辰（原"金蝶云·星辰"）是金蝶面向**小微企业**推出的SaaS业财税一体化产品，基于金蝶AI苍穹云原生PaaS平台构建。核心定位是"管账、管货、管生意"，提供财务云、税务云、进销存云、零售云、订货商城等云服务模块。

> 关键事实：官方在产品页面明确写"金蝶云·星辰现已升级为金蝶AI星辰"，这是产品改名/升级，不是两个不同产品。接待客户时如果对方说"云星辰"或"AI星辰"，指的是同一个东西。（来源：金蝶官网产品页 kingdee.com/product/small）

### 1.2 星辰与精斗云、KIS云、K3系列的定位区别

客户经常会问"这几个产品选哪个"，实施顾问要能讲清楚：

| 产品 | 定位 | 客户画像 |
|------|------|---------|
| **精斗云** | 最轻量的云财务/进销存工具 | 个体户、刚起步的小商户，业务简单、预算有限 |
| **金蝶AI星辰** | 比精斗云更完整的小微企业业财税一体化 | 成长型小微企业，有采购/销售/库存/生产等完整业务流程管理需求，功能覆盖进销存+财务+零售+订货商城 |
| **KIS云** | 传统KIS本地财务软件的云化延伸 | 有传统财务团队、习惯KIS账务处理逻辑、从KIS本地版迁移上云的企业 |
| **K3 WISE / 云星空** | 中大型企业ERP | 有完整供应链、生产制造、多组织管控需求的中型及以上企业 |

> 说明：以上定位区别综合了金蝶精斗云服务官网、多篇第三方金蝶代理商站点资料交叉确认，具体版本功能边界会随产品迭代调整，报价和功能清单请以金蝶官网最新信息或官方客服为准。

### 1.3 版本分级

金蝶AI星辰分为**标准版、专业版、旗舰版**三个版本，版本越高覆盖的业务场景越完整（比如旗舰版才支持完整的产供销一体化和生产管理模块）。给客户做方案时要先确认对方的实际业务需求（是否涉及生产、是否有零售门店、是否需要合并报表等），再匹配对应版本，避免出现"客户以为标准版就能做生产管理"这类预期错位。

（来源：金蝶官网产品页 kingdee.com/product/small 的版本功能对比表）

## 2. 财税管理

### 2.1 核心功能

星辰的财税管理和K3系列的"总账+应收应付+固定资产"体系是同一套逻辑，但操作更简化、面向不太懂财务专业术语的小微企业主：

| 模块 | 功能 |
|------|------|
| 账务处理 | 标准账务处理、期末智能结转、科目多维核算（最多支持12个辅助核算维度）、业务单据自动生成凭证 |
| 财务报表 | 三大报表（资产负债表/利润表/现金流量表）、自定义报表、多账套报表管理、多公司报表合并 |
| 资产管理 | 资产新增/变动/清理/拆分、计提折旧、资产与总账对账 |
| 出纳管理 | 现金银行日记账、智能识别银行流水、银企互联、出纳与总账对账 |
| 开票管理 | 数电发票、销售单据一键开票、发票红冲、电票交付全流程 |
| 纳税管理 | 智能取票发票认证、税负测算、增值税纳税申报表 |

（来源：金蝶官网产品页 kingdee.com/product/small 功能对比表）

### 2.2 客户常问：星辰能不能做多公司合并报表

**能，但要看版本**。星辰支持多账套报表管理，旗舰版支持多公司报表合并（三大合并报表、抵消分录、合并工作底稿）。如果客户只是标准版/专业版又有多公司合并需求，需要引导对方了解旗舰版功能，或评估是否该考虑升级到云星空。

### 2.3 智能识别与自动化能力

星辰强调"智能"，几个客户容易感兴趣的点：
- 发票导入识别自动生成凭证（免手工录发票明细）
- 业务单据（采购/销售）自动生成凭证，不需要像K3那样单独配置"凭证模板+科目映射"那么复杂，但灵活度也相对较低
- 银行流水智能识别，减少出纳手工核对工作量

## 3. 进销存管理

### 3.1 采购管理

星辰的采购单据链路比K3系列更简化，核心单据包括：

```
采购申请（可选） → 采购订单 → 采购入库/采购退货 → 采购发票单 → 付款
```

| 功能点 | 说明 |
|--------|------|
| 采购订单生成采购发票 / 采购入库生成采购发票 / 采购发票生成采购入库 | 三种方向都支持，单据之间下推关系比K3更灵活，客户可以按自己业务习惯选择先开票还是先入库 |
| 供应商价格策略 | 支持按订货量设置阶梯价 |
| 暂估入库期初 | 支持暂估处理，逻辑与K3的"货到票未到暂估"一致 |
| 采购限价、采购费用分摊商品成本 | 采购费用可以分摊进商品成本，与K3的"运费分摊"逻辑类似 |
| 以销定购、智能补货、采购价格记忆 | 星辰强调的智能化功能，K3系列没有对应的"智能记忆"能力 |

（来源：金蝶官网产品页 kingdee.com/product/small 功能对比表）

### 3.2 销售管理

```
销售报价单/销售预测单（可选） → 销售订单 → 销售出库/销售退货 → 销售发票单 → 收款
```

| 功能点 | 说明 |
|--------|------|
| 销售订单生成销售发票 / 销售出库生成销售发票 / 销售发票生成销售出库 | 同采购一样，三个方向的下推关系都支持 |
| 直运销售 | 供应商直接发货给客户，不经过自己仓库，与K3的"代发/直运"业务逻辑一致 |
| 委托代销 | 支持委托代销、委托代销结算、委托代销退货，这是星辰面向经销/代销业务场景的特色功能，K3系列没有直接对应的标准功能 |
| 客户价格策略 | 支持按销量设置阶梯价 |
| 车销、访销 | 面向快消/批发行业的移动销售场景，K3系列没有这类功能，是星辰的差异化卖点 |

（来源：金蝶官网产品页 kingdee.com/product/small 功能对比表）

### 3.3 客户常问：星辰的单据流程比K3简单，是不是功能弱

**要分场景回答**。星辰的单据链路确实比K3少了"到货单""收料通知单"这类中间环节，因为它面向的是小微企业，业务链路本身更短、更不需要多级质检/收货确认。但星辰也有K3没有的特色功能（车销访销、委托代销、订货商城直连客户下单），是"轻管控、重经营协同"的设计思路，和K3"重管控、重流程节点"的思路不是同一个方向，不能简单说谁功能强弱，要看客户实际业务复杂度匹配哪个。

## 4. 库存与出库成本核算

### 4.1 出库成本核算方法

星辰支持的计价方法（已通过第三方实操文章及金蝶代理商技术文章确认）：

| 计价方法 | 计算逻辑 |
|---------|---------|
| **移动平均法** | 每次入库后重新计算平均单价，逻辑与K3的移动加权平均法一致 |
| **加权平均法** | 按期间汇总计算平均单价 |
| **先进先出法** | 按入库时间顺序，先入库的先按其成本出库 |
| **个别计价法** | 每件商品单独识别其实际采购成本，适合贵重物品/有唯一标识的商品 |

> 说明：不同信息源对"加权平均法"的具体计算口径描述略有差异（部分资料称为移动平均法+加权平均法两种并列方法，另一些资料把两者视为同一方法的不同叫法），这一点建议实施时以客户实际系统里"存货核算参数"下拉选项的真实文案为准，不要凭手册直接下结论。计划成本法未在已核实的资料中找到星辰支持的明确依据，如果客户问星辰是否支持计划成本法，建议如实告知"需要在客户实际系统里确认，星辰的定位是小微企业简化核算，通常不像K3那样支持计划成本法"。

### 4.2 核算维度设置（客户常问）

星辰的计价方法配置位置和K3不同，路径是：**系统设置→系统参数→存货核算参数**。这里有一个关键选项决定了计价方法的作用范围：

- **按参数设置核算成本**：全公司统一用一种计价方法，参数上选哪个，所有商品都按这个方法核算
- **按商品设置核算成本**：不同商品可以单独设置不同的计价方法，需要在"商品设置"里逐个/批量配置

**回答客户提问的建议话术**：如果客户的商品种类不多、计价方式统一，建议用"按参数设置"省心；如果客户有部分高价值商品需要个别计价、其他商品用移动平均，才需要用"按商品设置"分别配置，避免不必要的复杂度。

（来源：第三方金蝶服务商技术文章 dyanyun.com/article/84.html，描述了这两个核算维度选项及配置路径）

### 4.3 出库成本核算常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 出库成本核算未核算出成本 | 已结转成本不会重算（包含生成失败的暂存凭证） | 检查生成凭证界面是否已存在成本结转凭证或暂存凭证，需先删除再重新核算 |
| 销售退货无源单导致成本算不出 | 未设置无源单退货的成本来源取数规则 | 到【系统参数】-【存货核算参数】设置无源单退货成本来源取数规则 |
| 启用第一期，商品成本算不出 | 期初只录入了数量，没有录入成本金额 | 反结账到启用期，补录期初成本金额 |

（来源：第三方金蝶服务商技术文章 erpjdy.cn/1587.html，星辰出库成本核算操作教程）

### 4.4 库存管理其他功能

| 功能 | 说明 |
|------|------|
| 库龄分析、保质期预警 | 与K3的呆滞预警逻辑一致 |
| 移仓、同价/异价调拨 | 仓库间调拨，异价调拨是星辰的特色（调拨时可以按不同价格计价，K3标准调拨通常按同一成本平移） |
| 组装拆卸、形态转换单 | 简单的组合商品拆装场景，比K3的"BOM/KIT件"更轻量 |
| 多人盘点 | 支持多人协同盘点 |

## 5. 零售管理

这是星辰区别于K3系列的一个重点模块——K3 WISE/云星空没有专门的零售门店管理功能，星辰有完整的零售/门店/私域运营能力，是产品差异化的核心卖点之一：

| 功能分类 | 具体功能 |
|---------|---------|
| **门店管理** | 智慧门店管理、门店零售价/调价单、多门店统一调拨 |
| **收银** | POS收银系统、POS端配送台、生鲜称重、客户自助开单 |
| **会员与营销** | 积分管理、100+促销组合、多种赠券方式（会员有礼、充值、次卡等）、精准营销 |
| **门店商城** | 小程序商城/H5商城、门店商城后台管理、用户个人主页 |
| **要货配货** | 智能要货配货铺货、一键要货/配货、统一调拨 |
| **轻餐管理** | 面向餐饮场景（标准版不支持对接外卖服务，需注意版本限制） |

（来源：金蝶官网产品页 kingdee.com/product/small 功能对比表，及金蝶AI星辰零售管理产品页 kingdee.com/product/stellar_retail.html）

**客户常问：K3能不能做零售门店管理**——不能，这是星辰的专属能力。如果客户主业务是零售连锁/多门店经营，星辰的零售云模块是比K3系列更合适的选择；反过来如果客户是纯批发/制造企业没有零售门店需求，零售模块用不上。

## 6. 多账套/多单位管理

### 6.1 星辰支持多账套

金蝶AI星辰支持建立多个账套（官方也称"多单位管理"），适合客户名下有多家独立核算的小公司/门店的场景。这一点与K3 WISE的"多账套模拟多组织"思路类似，但星辰面向的是更轻量的场景（比如一个老板开了几家分店，每家分店独立记账）。

（来源：金蝶AI星辰官网文章 jdy.com/article/1965668575964377090.html"金蝶迷你版仅单单位做账？AI星辰多单位管理更高效"，以及精斗云服务官网关于星辰多账套建立流程的文章）

### 6.2 常见问题

| 问题 | 说明 |
|------|------|
| 客户问星辰是否支持多组织协同（类似云星空的组织间结算） | 未找到明确依据表明星辰有类似云星空"组织间委托销售/采购/结算"的原生功能。星辰的多账套更偏向"多个独立核算主体分别管理"，如果客户需要账套间自动生成往来结算，建议实地核实客户实际使用的版本，不要凭手册直接承诺 |
| 客户从精斗云或KIS云升级到星辰，账套数据能不能迁移 | 未找到明确依据，建议按金蝶官方数据迁移服务的实际支持范围现场确认，不同产品间的数据结构存在差异，不是简单的备份还原 |

## 7. 生产与委外管理

星辰旗舰版提供小微企业的产供销一体化能力，包含简化版的生产和委外管理（比K3的MRP+生产订单体系更轻量）：

| 模块 | 核心功能 |
|------|---------|
| 生产管理 | BOM管理（多级维护、批量修改）、物料需求建议、齐套分析、生产任务单、生产领料/退料、倒冲领料、生产成本核算 |
| 委外管理 | 委外加工单、委外发料/退料、委外倒冲发料、委外成本核算 |
| 受托加工 | 受托加工订单、客供材料入库/退货，面向"接单加工"型小微制造企业 |

（来源：金蝶官网产品页 kingdee.com/product/small 功能对比表）

**客户常问：星辰的生产管理和K3的MRP是一回事吗**——核心逻辑类似（都是BOM+需求计算+领料+入库核算），但星辰的"物料需求建议"是简化版，不像K3 MRP那样有独立的运算范围限定、例外信息报告等精细化管理功能，适合工艺流程相对简单的小型工贸企业，复杂多层BOM、大批量排产的场景建议评估K3系列。

## 8. 常见客户问题速查

| 客户问题 | 建议回答方向 |
|---------|-------------|
| "云星辰和AI星辰是两个产品吗" | 不是，AI星辰是云星辰的官方新名字，2023年产品升级后统一改名，功能是延续关系 |
| "星辰能替代K3吗" | 不能简单替代，两者定位不同：星辰面向小微企业，轻量化、强调经营协同（零售、订货商城、车销访销）；K3面向中大型企业，强调多组织管控和复杂供应链流程。企业规模和业务复杂度增长到一定程度，通常需要从星辰升级到云星空 |
| "星辰支持哪几种成本计价方法" | 移动平均法、加权平均法、先进先出法、个别计价法，配置路径在系统参数-存货核算参数，可以选全公司统一或按商品单独设置 |
| "星辰能不能开多个账套/管理多家门店" | 支持多账套/多单位管理，但账套间没有像云星空那样的自动化组织间结算能力（此点未找到官方明确依据，需现场核实） |
| "星辰有没有零售门店管理功能" | 有，这是星辰的重点模块之一，包含POS收银、会员营销、门店商城小程序等，是K3系列没有的能力 |
