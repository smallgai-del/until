## 1. 产品定位与产品矩阵

### 1.1 精斗云是什么

金蝶精斗云是金蝶旗下面向**小微企业/个体户**的SaaS云服务品牌，官方定位"小微企业一站式财税云服务平台"。它是金蝶最早一批面向小微客户的云产品线（前身为友商网，2016年变更为精斗云品牌），比金蝶AI星辰更轻量、更基础。

（来源：金蝶官网产品页 kingdee.com/product/jdy；精斗云云进销存V3.0官方操作手册，明确写"云进销存是金蝶公司推出的第一款在线进销存软件，由成立于2008年的友商网研发，2016年变更为精斗云品牌"）

### 1.2 精斗云的产品矩阵

精斗云不是单一产品，而是一个产品矩阵，客户购买时经常会问"这几个是不是同一个东西"，需要能区分清楚：

| 产品 | 定位 |
|------|------|
| **云ERP** | 小型企业智慧成长服务平台 |
| **云会计** | 微型企业智能财务管理云服务 |
| **云进销存** | 微型企业生意管理好帮手（采购/销售/库存/资金） |
| **云报销** | 免费易用的费用报销工具 |
| **账无忧** | 代账公司专属财务管理软件 |
| **金蝶KIS云** | 小微企业业财一体化管理平台（注：金蝶KIS云在精斗云官网的产品矩阵中展示，与传统KIS本地版是不同的产品形态） |
| **精斗云企业微信版** | 企业生意管理好帮手（企业微信生态内使用） |
| **精斗云APP** | 手机端生意管理 |

（来源：精斗云服务官网 erpjdy.cn 常见问题页面产品导航栏）

> 重要澄清：客户如果问"精斗云和KIS云是一个产品吗"——不是完全一样的产品，但两者都属于精斗云官网展示的产品矩阵范畴，是金蝶小微产品线下的不同细分产品。具体两者功能边界差异，建议实施时进一步核实（本手册的KIS云调研会单独补充）。

### 1.3 精斗云 vs 金蝶AI星辰（云星辰）的定位区别

这是客户最常问的对比问题：

| 维度 | 精斗云 | 金蝶AI星辰 |
|------|--------|-----------|
| 定位 | 最基础的轻量级云财务/进销存工具 | 比精斗云更完整的小微企业业财税一体化 |
| 目标客户 | 个体户、刚起步的小商户，业务简单、预算有限 | 成长型小微企业，有采购/销售/库存/生产等完整业务流程管理需求 |
| 功能覆盖 | 云会计+云进销存两大基础模块 | 财务云+税务云+进销存云+零售云+订货商城+生产管理，模块更全 |
| 零售/门店管理 | 未在精斗云产品矩阵中找到专门的零售门店管理模块 | 有完整的零售云（POS收银、会员营销、门店商城小程序） |
| 生产管理 | 未找到明确依据表明精斗云支持生产管理 | 旗舰版支持简化版生产管理（BOM、领料、委外） |

> 说明：以上对比综合精斗云服务官网多篇产品对比文章及金蝶AI星辰官网选型指南整理。具体某一细分功能是否完全没有，建议以客户实际购买版本的系统界面为准，因为产品功能会随版本迭代调整。

## 2. 云会计

### 2.1 核心定位

云会计是精斗云的财务记账模块，面向没有专业财务团队或财务能力有限的小微企业主，操作比K3系列、甚至比星辰的财税模块更简化。

### 2.2 建账与账套

- 云会计**3账套起售**，可选购10账套、20账套等不同规格套餐，个人版默认含20个账套
- 每购买1个账套额度，就可以为1家公司单独建账
- 新建账套只有**服务管理员**权限才能操作，需要填写公司编码、公司名称、基本资料等信息

（来源：精斗云服务官网 erpjdy.cn/1566.html"金蝶精斗云可以建多个账套吗"）

### 2.3 客户常问：云会计能不能做多公司合并报表

未找到明确依据表明云会计支持多公司合并报表功能（这是星辰旗舰版才有的能力）。云会计的多账套更偏向"多家独立小公司分别记账"，账套之间数据互相独立，如果客户有合并报表需求，建议引导了解星辰旗舰版或云星空。

## 3. 云进销存

### 3.1 七大模块

精斗云云进销存的官方操作手册明确将功能划分为**七大模块**：

```
电商、购货、销货、仓库、资金、资料、设置
```

| 模块 | 核心功能 |
|------|---------|
| **电商** | 对接线上店铺订单，实现线上交易的进销存联动 |
| **购货** | 采购下单、入库、供应商管理 |
| **销货** | 销售下单、出库、客户管理 |
| **仓库** | 库存查询、出入库记录、盘点 |
| **资金** | 收付款、往来核销 |
| **资料** | 商品、客户、供应商等基础档案 |
| **设置** | 系统参数、权限、账套配置 |

（来源：精斗云官方文档《云进销存V3.0操作手册》，cdn.jdy.com/jdy/helpDoc/yjxc/。手册原文描述云进销存"具有快速处理线上交易、即时查看业务数据、权限管理多端应用、特色功能随需购买等特性"，"是企业全面实现购、销、存和应收款专业处理的必备工具"）

### 3.2 精斗云的单据流程比K3/星辰更简化

精斗云面向的是业务最简单的小微商户，单据链路比星辰更短，通常直接是：

```
采购下单 → 入库 → （可选）供应商对账
销售下单 → 出库 → （可选）客户对账
```

没有K3系列的"暂估入库/发票冲回""到货单/检验单"这类中大型企业的流程节点，也没有星辰的"直运销售""委托代销"等相对复杂的业务模式（未在已核实资料中找到精斗云支持这些高级业务模式的依据）。

### 3.3 客户常问：精斗云能不能对接电商平台

**能**，"电商"是精斗云云进销存的七大模块之一，用于对接线上店铺订单，实现"业务与财务一体化管理"——官方案例提到"多网店如何实现业务与财务一体化管理"这个场景正是精斗云的典型应用（来源：金蝶官网案例文章 kingdee.com/article/1516351176646348801.html）。

## 4. 成本核算与结转

### 4.1 计价方法

精斗云进销存支持的成本核算方法，与星辰类似的几种基础方法（加权平均法为主，具体是否等同星辰的"移动平均法/加权平均法/先进先出法/个别计价法"四种全部支持，本次调研未找到精斗云官方逐一列出计价方法清单的一手资料，只能确认加权平均法是精斗云的核心计价逻辑）。

> 说明：搜索到的第三方资料（如简道云的"精斗云进销存计算方法详解"）多次提及"加权成本"的计算逻辑，但精斗云官方是否像星辰一样支持"按商品单独设置计价方法"这一灵活配置，未找到明确依据，建议实施时以客户实际系统里的成本设置选项为准。

### 4.2 结转成本操作

精斗云进销存的成本结转是一个独立的操作步骤，客户常见的疑问是"为什么我的成本没有自动算出来"：

| 场景 | 说明 |
|------|------|
| 结转成本时机 | 需要手工触发或按设置的规则执行结转，不是所有单据审核后立即算成本 |
| 结账 | 精斗云有独立的"结账"操作，结账后当期单据处理会受限，与K3系列的"期末关账"逻辑类似但操作更简化 |
| 历史账目调整 | 官方提供"智能调账"功能，用于结转/结账后发现数据有误时的调整（来源：金蝶AI星辰官网文章"金蝶精斗云进销存历史账目调整指南：智能调账功能详解"） |

### 4.3 常见问题

| 问题 | 排查方向 |
|------|---------|
| 成本结转不出来 | 检查是否有未审核的采购/销售单据；检查是否已执行"结转成本"操作 |
| 库存数量对但成本金额不对 | 检查入库单价是否录入正确，是否存在历史调账未生效的情况 |

## 5. 多账套管理

### 5.1 账套购买规则

精斗云的账套不是无限的，是**跟着购买套餐走**的付费资源：

| 产品 | 起购规则 |
|------|---------|
| 云会计 | 3账套起售，可选10账套/20账套等规格，个人版含20账套 |
| 云进销存 | 默认包含1个账套 |

一般是"购买几个账套，就能给几家公司建账"，账套不够用需要额外加购。

（来源：精斗云服务官网 erpjdy.cn/1566.html）

### 5.2 账套间数据独立

多账套之间的财务数据、业务数据完全独立，每个账套需要单独设置账套参数、科目设置、初始数据。操作人员要注意区分自己当前在操作哪个账套，避免跨账套误操作导致数据混淆。这一点与K3 WISE的多账套逻辑本质相同，只是精斗云的账套开通和切换操作更简单（面向不太懂IT操作的小微业主）。

### 5.3 客户常问：精斗云的账套和星辰/KIS云的账套能不能互通

未找到明确依据。精斗云、星辰、KIS云是金蝶不同的产品线，账套数据结构大概率不互通，如果客户有从精斗云升级到星辰或KIS云的需求，建议按金蝶官方数据迁移服务的实际支持范围现场确认，不能凭手册直接承诺可以无损迁移。

## 6. 常见客户问题速查

| 客户问题 | 建议回答方向 |
|---------|-------------|
| "精斗云和金蝶AI星辰有什么区别" | 精斗云更基础、更便宜，适合个体户和刚起步的小商户；星辰功能更全（多了零售门店、订货商城、生产管理等），适合有一定业务复杂度的成长型小微企业 |
| "精斗云能不能做多个店铺/多家公司的账" | 能，通过购买多账套实现，账套数量跟购买套餐挂钩，账套间数据互相独立 |
| "精斗云进销存包含哪些功能" | 官方明确的七大模块：电商、购货、销货、仓库、资金、资料、设置 |
| "精斗云能不能对接网店" | 能，"电商"模块专门用于对接线上店铺订单 |
| "精斗云的成本怎么算，为什么没自动出来" | 精斗云的成本核算需要执行"结转成本"操作，不是单据审核就自动算，建议检查是否有未审核单据、是否已触发结转 |
| "精斗云能不能做生产管理" | 未找到明确依据表明精斗云支持生产管理，这类需求通常建议客户考虑星辰旗舰版或K3系列 |
