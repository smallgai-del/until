## 1. 产品定位与版本分级

### 1.1 KIS云是什么

金蝶KIS云是金蝶为响应国家推动企业上云用云部署要求，结合中小微企业管理实际需求打造的云服务产品，核心卖点是"按需购买、最小投入""无需自购服务器""金蝶专业运维、当天交付""账套每天自动备份""异地云上办公"。

（来源：金蝶官网产品页 kingdee.com/products/kiscloud.html）

### 1.2 KIS云四个版本

KIS云不是单一产品，而是按企业规模和管理需求分了四个版本，客户经常会问"我该选哪个"：

| 版本 | 定位 | 核心场景 |
|------|------|---------|
| **KIS云·迷你版** | 创业型企业简单财务核算 | 解决手工账务混乱问题，总账/报表/出纳，快速上手 |
| **KIS云·标准版** | 微型企业精细财务核算 | 总账、工资、固定资产、出纳、往来核销对账、账龄分析 |
| **KIS云·专业版** | 中小微工贸企业一站式云服务 | 涵盖采购、生产、仓存、销售、财务到移动经营全业务环节，实时库存监控、订单全程跟踪、多维财务核算、线上订货和移动销售 |
| **KIS云·旗舰版** | 深化数字化转型 | 以销定产、全网触达客户、移动办公审批、异地多仓库统一管控、业务财务数据无缝连接 |

（来源：金蝶官网产品页 kingdee.com/products/kiscloud.html，版本介绍原文）

**回答客户提问的建议话术**：如果客户只是想解决"记账混乱"这种最基础的财务需求，迷你版/标准版就够；如果客户有采购、生产、销售全流程管理需求，需要专业版；如果客户已经有多仓库、想做全渠道全网营销、精细化生产成本管控，才需要考虑旗舰版。不要一上来就推最贵的版本，先问清楚客户的实际业务环节有多少个。

### 1.3 KIS云与传统KIS本地版的关系

未在金蝶官方页面找到"KIS云是传统KIS专业版/迷你版的云端延伸"这一说法的逐字确认，但从版本命名（KIS云·专业版、KIS云·迷你版、KIS云·标准版都直接对应传统KIS本地版的同名版本）以及功能模块的高度相似性（总账、报表、往来核销、固定资产等）来看，可以合理判断**KIS云延续了传统KIS本地部署版本的产品体系和命名，是云端部署形态的延伸**，而不是完全独立重新设计的产品。

> 建议话术：如果客户问"我原来用的KIS本地版能不能直接切换成KIS云"，如实告知——版本体系和功能模块名称是延续的，但具体数据能否直接迁移、账套结构是否完全兼容，需要金蝶官方迁移服务现场评估，不能凭产品名称相似就直接承诺无损迁移。

## 2. KIS云与精斗云、AI星辰的定位区别

客户常问"这三个都是小微企业产品，有什么不一样"，需要讲清楚：

| 产品 | 技术/产品脉络 | 特色能力 |
|------|--------------|---------|
| **精斗云** | 金蝶最早一批面向小微客户的云产品（前身友商网），云会计+云进销存两大基础模块 | 最轻量、最基础，多店铺电商对接 |
| **金蝶AI星辰** | 原"云星辰"，基于金蝶AI苍穹云原生PaaS平台构建的新一代产品 | 零售门店管理、订货商城、车销访销、委托代销，功能覆盖面最广 |
| **金蝶KIS云** | 延续传统KIS本地版的产品体系和命名，云端部署形态 | 分四个版本精细分级，专业版/旗舰版覆盖生产制造（BOM、物料需求计划），且有自己的**BOS**二次开发平台 |

（来源：三个产品的金蝶官网产品页交叉比对，及精斗云服务官网关于产品矩阵的介绍文章）

**关键差异点**：KIS云的专业版/旗舰版是这三个"小微产品"里**唯一明确带有生产制造模块**（支持BOM、物料需求计划、生产任务管理、生产过程管理）的，如果客户是工贸企业、有生产环节，KIS云专业版/旗舰版比精斗云、比AI星辰标准版/专业版更合适；如果客户是纯贸易/零售，没有生产环节，精斗云或AI星辰的性价比可能更高。

> 说明：AI星辰旗舰版也支持生产管理（参见《金蝶AI星辰_实施学习手册》第7节），所以严格来说不是"唯一"，但KIS云的生产模块历史更悠久、延续自传统KIS工贸版的成熟功能，这一点是KIS云的差异化优势，实施时可以此作为选型建议依据。

## 3. 财务管理模块

KIS云专业版V16.0/旗舰版V7.0的财务管理模块（来源：金蝶官网版本对比表）：

| 功能 | 说明 |
|------|------|
| 总账 | 核心账务处理 |
| 报表 | 标准财务报表 |
| 网上银行 | 银企对接 |
| 资金管理 | 资金计划、资金分析 |
| 应收款管理 / 应付款管理 | 往来核销、账龄分析 |
| 固定资产 | 资产卡片、折旧计提 |
| 出纳管理 | 现金银行日记账 |
| 智能记账 | 自动化记账辅助 |
| 多账簿报表 | 支持多账簿并行核算 |

### 3.1 客户常问：KIS云能不能做多账套

未在本次调研的一手资料中找到KIS云"多账套"支持范围的逐字说明（不同于精斗云已明确的"3账套起售"规则）。建议实施时直接在客户实际购买的KIS云版本后台核实账套数量和购买规则，不要照搬精斗云的账套购买逻辑，两者是不同的产品体系。

## 4. 供应链与生产制造模块

### 4.1 供应链管理

| 功能 | 说明 |
|------|------|
| 采购管理 | 采购全流程 |
| 销售管理 | 销售全流程 |
| 仓存管理 | 库存管理 |
| 存货核算 | 官方版本对比表列出"存货核算"为独立功能项，具体支持的计价方法（是否包含全月平均/移动平均/先进先出/个别计价/计划成本）未找到官方逐一列出的明确依据，建议实施时以客户实际系统里的存货核算参数选项为准 |
| 委外加工 | 委外业务管理 |
| 客户管理 | 客户档案与关系管理 |

### 4.2 生产制造（专业版/旗舰版特色）

| 功能 | 说明 |
|------|------|
| 生产数据管理 | 生产基础数据 |
| 支持BOM | 物料清单管理 |
| 物料需求计划 | 支持采购建议——即MRP的简化版能力，与K3 WISE的MRP逻辑类似但面向工贸型小微企业 |
| 生产任务管理 | 生产任务单 |
| 生产过程管理 | 生产过程跟踪 |
| 成本管理-实际成本 | 官方明确写"成本管理：实际成本"，可以确认KIS云采用**实际成本法**，未找到支持标准成本法/计划成本法的依据 |

（来源：金蝶官网 kingdee.com/products/kiscloud.html 版本对比表）

### 4.3 客户常问：KIS云的生产管理和K3系列的MRP是一回事吗

核心逻辑类似（都是BOM+需求计算+生产任务），但KIS云面向的是"中小微工贸企业"，功能颗粒度介于精斗云/AI星辰的简化版和K3系列的完整MRP之间。具体客户的生产环节有多复杂（是否多层BOM、是否需要精细排产），决定了该用KIS云还是应该考虑K3系列。

## 5. BOS平台与移动应用

### 5.1 KIS云自己的BOS平台

这是KIS云的一个重要差异化能力——官方版本对比表明确列出KIS云有自己的**BOS**功能模块：

| BOS功能 | 说明 |
|---------|------|
| **BOS数据交换平台** | 用于数据导入导出、系统间数据交换 |
| **BOS万能报表工具** | 自定义报表开发，与K3系列的"万能报表工具"概念类似 |
| **BOS集成开发工具** | 二次开发/系统集成 |

（来源：金蝶官网 kingdee.com/products/kiscloud.html 版本对比表"BOS"分类下明确列出这三项）

> 重要澄清：KIS云的BOS、K3 WISE的BOS（K/3 Business Object System）、K3Cloud的BOS（K/3 Cloud Business Operation System）**是三套不同产品各自独立的开发平台**，尽管名字都叫"BOS"，但适用范围互不重叠，插件和开发方式都不能跨产品复用。客户/同事交流时如果提到"BOS"，一定要先确认说的是哪个产品的BOS。

### 5.2 移动应用

| 应用 | 说明 |
|------|------|
| 金蝶云APP | 支持通过移动端访问账套、查询报表、录入单据、完成下单、审批、数据分析 |
| KIS云小程序 | 扫码体验，移动办公场景 |

（来源：金蝶官网产品页 kingdee.com/products/kiscloud.html）

### 5.3 公用功能与其他模块

| 功能分类 | 具体项 |
|---------|--------|
| 发票管理 | 销项发票（纸票/电票）、进项发票 |
| HR | 工资管理、组织规划、职员管理、合同管理、考勤管理 |
| 电子商务 | 订单服务、售后服务、财务服务、经营分析 |
| 商业零售管理 | 商品配置、门店系统、报表中心、微门店、移动POS |
| 全网营销 | 会员管理、微商城、微CRM、微客户、微销售 |
| 加盟店管理 | 加盟店收银、库存管理、微采购 |
| 公用功能 | 业务流程设计、数据授权、单据自定义、基础资料 |

（来源：金蝶官网 kingdee.com/products/kiscloud.html 版本对比表）

**客户常问：KIS云也有零售/门店管理吗**——有，官方版本对比表列出了"商业零售管理"（微门店、移动POS）和"全网营销"（微商城、加盟店管理）功能，这一点和AI星辰的零售云模块有一定重叠，如果客户同时问"KIS云和AI星辰哪个零售功能更强"，本次调研未找到两者零售模块的详细对比资料，建议以客户实际业务场景（是否需要生产制造）作为主要选型依据，而不是零售功能本身。

## 6. 常见客户问题速查

| 客户问题 | 建议回答方向 |
|---------|-------------|
| "KIS云和精斗云、AI星辰有什么区别" | KIS云延续传统KIS的产品体系，分迷你/标准/专业/旗舰四档，专业版起支持生产制造（BOM、物料需求计划），这是它和精斗云、AI星辰标准配置相比的差异化优势；精斗云最轻量；AI星辰功能覆盖面最广（零售门店+订货商城+生产） |
| "我原来用KIS本地版，能直接换KIS云吗" | 版本体系和功能模块是延续的，但具体数据迁移、账套兼容性需要金蝶官方现场评估，不能凭版本名称相似直接承诺无损迁移 |
| "KIS云支持生产管理吗" | 专业版和旗舰版支持，包含BOM、物料需求计划（支持采购建议）、生产任务管理、生产过程管理，成本核算用实际成本法 |
| "KIS云的BOS和K3的BOS是一个东西吗" | 不是，KIS云、K3 WISE、K3Cloud三个产品各有自己独立的BOS开发平台，功能定位类似（都是二次开发/报表/数据交换），但技术实现和插件体系互不兼容 |
| "KIS云能不能做多账套" | 未找到官方明确说明，建议直接在客户实际购买的版本后台核实，不要套用精斗云的账套规则 |
